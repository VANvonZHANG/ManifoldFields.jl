# Example data

All datasets ship in one immutable artifact described by `Artifacts.toml`
(hosted on this repository's GitHub Releases) and are fetched on demand by both
language tracks — nothing here is bundled with `Pkg.add("ManifoldFields")`.

| File | Origin | Used in |
|---|---|---|
| `oQU480.grid.nc`, `oQU480.data.nc` | MPAS ocean quadrilateral grid (UXarray tutorial data, ~4.7 MB + 20 KB) | ch02 Python: opening MPAS natively |
| `oQU480.ugrid.nc` | generated by `scripts/prepare_ugrid.py` (uxarray `to_xarray`, UGRID output) | ch02: the foreign-topology boundary demo |
| `psi_healpix.nc` | UXarray HEALPix example (nside = 32 streamfunction, 12 288 cells, no coordinates) | ch02: HEALPix ordering |
| `latlon_analytic.nc`, `cubedsphere_analytic.nc`, `healpix_analytic.nc` | generated by `scripts/make_julia_data.jl`: `psi = cosd(lat)·sind(lon) + 0.3·sind(2lat)` at cell centroids, `CellLoc`, `save_ugrid` | ch01, ch03, ch04 (both languages; analytic ground truth) |

The data variable in `oQU480.ugrid.nc`, `bottomDepth`, is an ocean bottom depth in
meters; the `to_xarray` conversion in `scripts/prepare_ugrid.py` drops the source
`units`/`long_name` attributes, so the file itself carries no units metadata.

## Interop measurements

Environment: uxarray 2026.7.0 × ManifoldFields 0.1.0 (measured on 2026-09-06).

**Julia writes → UXarray reads** (`healpix_analytic.nc`): works: open OK, 12288 cells,
value ranges agree to <1e-6 — UXarray reads `psi` ∈ [-1.136151774866946, 1.1361517343765501],
bit-identical to the Julia-side extrema printed when the file was written. Measurement
note: the open prints two harmless "coordinates are not regularly spaced" messages, and
uxarray 2026.7.0 exposes the face count as the integer `uxds.uxgrid.n_face` — the older
`nMesh2_face` accessor no longer exists.

**UXarray writes → Julia reads** (`oQU480.ugrid.nc`): expected and observed: `load_ugrid`
raises

```
ArgumentError: UGRID dataset has no data variables (variables with a mesh attribute)
```

because uxarray `to_xarray` writes `bottomDepth` with no attributes at all — in
particular without the `mesh` pointer to `grid_topology` that `load_ugrid` uses to
discover data variables — so the load fails at variable discovery, before any grid
reconstruction is attempted. Rationale: ManifoldFields reconstructs one of its four
grid types from own-file UGRID metadata; an arbitrary MPAS quad topology matches none
of them. `load_ugrid(path; mesh = m)` exists for foreign files whose geometry *does*
match a ManifoldMeshes grid.
